# Tecnologías autorizadas — TNS Engineering

## Backend
- **.NET 10+** — APIs REST, microservicios, agentes IA
- **Python 3.11+** — exclusivo para área de Datos y ML
- No está autorizado: Node.js, Java, PHP, Ruby

## Frontend
- **Angular 17+** — aplicaciones web empresariales
- No está autorizado: React, Vue, Svelte para proyectos nuevos

## Base de datos
- **SQL Server 2019+** — datos transaccionales
- **PostgreSQL 15+** — proyectos de datos y analítica
- **Redis 7+** — caché y sesiones
- No está autorizado: MongoDB, MySQL, Oracle para proyectos nuevos

## Nube
- **Microsoft Azure** — proveedor principal
- Servicios autorizados: App Service, AKS, Azure Functions, 
  Azure AI Search, Azure Service Bus, Azure SQL
- No está autorizado: AWS, GCP sin aprobación del comité de arquitectura

## Mensajería
- **Azure Service Bus** — comunicación asíncrona entre servicios
- **SignalR** — comunicación en tiempo real con clientes web
- No está autorizado: RabbitMQ, Kafka sin aprobación previa

## IA y LLM
- **Azure OpenAI** — modelos GPT autorizados (GPT-4o, GPT-4o-mini)
- **Semantic Kernel** — orquestación de agentes en .NET
- No está autorizado: llamadas directas a OpenAI API sin pasar por Azure
